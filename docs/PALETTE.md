# NewBe Palette

## Core Gold

| Token | Value | Purpose |
|---|---|---|
| Gold | `#D6A928` | Primary accent |
| Gold Bright | `#E4BE45` | Hover/highlight |
| Gold Dark | `#A77A12` | Pressed/deep accent |

## Light Surfaces

| Token | Value |
|---|---|
| Background | `#E8E6DF` |
| Secondary | `#D8D6CF` |
| Raised | `#F3F1EA` |
| Text | `#20211F` |
| Secondary Text | `#595B57` |
| Border | `#8E908A` |

## Dark Surfaces

| Token | Value |
|---|---|
| Background | `#272927` |
| Secondary | `#343633` |
| Raised | `#41433F` |
| Text | `#F0EEE7` |
| Secondary Text | `#BBBDB7` |

## Design rule

Gold should identify focus, selection, activity, and NewBe identity.

It should not dominate every surface.

# Changelog

## 0.1.0-alpha.1 — 2026-08-19

Initial public preview of the NewBe desktop experience.

- Light and dark GTK 3/GTK 4 themes
- GNOME Shell theme and preferences extension for GNOME 50
- NewBe icon theme with complete coverage of the 46-app baseline
- Fifteen-design NewBe cursor theme with HiDPI sizes and compatibility aliases
- Seven original wallpapers with GNOME Background integration
- User-scoped installer, uninstaller, audits, reproducible release packaging, and CI validation
- Split MIT software and CC BY-SA 4.0 visual-art licensing
